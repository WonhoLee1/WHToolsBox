WHTOOLS TV Drop Motion Simulator

Control Center — 상세 사용자 매뉴얼
MuJoCo 기반 TV 패키지 낙하 시뮬레이션 통합 제어 인터페이스
v6.0

개요

WHTOOLS Control Center는 run_drop_simulation_cases_v6.py를 실행하면 자동으로 열리는 MuJoCo 기반 TV 패키지 낙하 시뮬레이션의 통합 제어 패널입니다. 시뮬레이션 실시간 제어, 모델 파라미터 편집, 구조 해석 파이프라인 실행, FEM 모델 내보내기까지 하나의 창에서 모두 수행할 수 있습니다.

⚡ 주요 기능 요약
기능설명
실시간 시뮬레이션 제어Play / Pause / Reset, 슬로우모션, 타임라인 스크럽
모델 파라미터 편집치수·물성·접촉·용접 조건 등 전 파라미터 실시간 수정
ISTA 낙하 시나리오PARCEL / LTL 시퀀스 자동 생성 및 배치 시뮬레이션
구조 해석Von-Mises 응력 / 변형장 자율 분석 (JAX 가속)
FEM 모델 내보내기OpenRadioss / ParaView / LS-PrePost 연계
관성 보정목표 질량·CoG·MoI 자동 계산 및 가상 바디 삽입

실행 방법

프로젝트 루트 디렉터리에서 다음 명령으로 실행합니다:

python TVPackageMotionSim/run_drop_simulation_cases_v6.py

실행 시 터미널에 ASCII 아트 타이틀이 출력된 뒤, MuJoCo Viewer 창과 Control Center 창이 함께 열립니다. Control Center는 MuJoCo Viewer의 오른쪽 상단 위치에 자동으로 정렬됩니다.

창 자동 정렬: MuJoCo Viewer를 이동하면 Control Center가 그 옆에 따라붙습니다. DPI 배율이 적용된 환경(고해상도 모니터)에서도 정확히 정렬됩니다.
시뮬레이션 케이스: 파일 하단 __main__ 블록에서 실행할 케이스 함수를 지정합니다. 기본값은 test_case_1_setup() (Corner 2-3-5, 낙하 높이 0.3 m)입니다. cfg["use_viewer"] = True가 설정되어 있어야 Control Center가 활성화됩니다.

🎲 균일 근사 자동 계산 (Guess Uniform)

패키지 치수(W×H×D)와 SET 치수, 목표 질량을 기반으로 균일 밀도 직육면체로 가정한 Ixx, Iyy, Izz를 자동 계산하여 채워줍니다. 측정값이 없을 때 초기 추정치로 활용합니다. Package 70% + SET 30% 가중 평균 치수를 사용합니다.

⚡ 관성 보정 계산 (Calculate)

현재 입력값으로 시뮬레이션 모델의 실제 관성(Base)과 목표 관성의 차이(Delta)를 계산합니다.

결과 컬럼의미
Base현재 시뮬레이션 모델의 실제 관성값
Target사용자가 입력한 목표값
Delta보정에 필요한 차분값
Feasibility✅ Exact: 물리적으로 유효 / ⚠️ Neg diag: MoI 대각 음수 → 목표값 조정 필요
물리적 유효성: MoI 대각 성분에 음수가 발생(Neg diag)하거나 고유치가 유효하지 않으면 물리적으로 실현 불가능한 관성 텐서입니다. Guess Uniform으로 초기값을 재산정 후 조정하십시오.
