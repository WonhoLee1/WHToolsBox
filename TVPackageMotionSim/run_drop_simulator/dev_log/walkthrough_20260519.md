## 4. [추가 작업] 관성 텐서 고유치(Eigenvalues) 분석 및 사전 예외 방지 파이프라인

## 6. [물리 역산 완벽 싱크] 다이얼로그 계산값과 실제 빌드 모델 조립 관성 간 불일치 타결
UI 다이얼로그의 표에서는 오차가 없는 `Exact` 상태로 표시됨에도 불구하고, 최종 생성된 실제 시뮬레이션 모델 조립체에 대한 물리 요약 리포트(터미널 출력)에서는 `MoI Diag`가 타겟과 미세한 오차(예: `⚠️ 6.0%`)를 내며 실패로 뜨는 논리적 불일치를 완전히 해결했습니다.
* **해결 방안: 역산 평행축 정리 (Inverse Parallel Axis Theorem) 전격 반영:** 조립 후 최종 관성이 목표치 `t_moi`와 정확히 싱크를 이루도록, 가상 보정 바디의 자체 무게중심 `pos_delta` 기준의 순수 보정 관성 `i_delta`를 다음과 같이 역산하여 계산 단계에서 선차감해 주었습니다:
  $$I_{\delta} = I_{target} - I_{base\_at\_tcog} - I_{parallel\_axis}(m_{\delta}, d_{\delta})$$
  여기서 $d_{\delta} = pos\_delta - t\_cog$ 입니다.
* **적용 후 효과:** 실제 빌드된 최종 시뮬레이터 모델의 `Final MoI`와 사용자가 지정한 `Target MoI` 간의 합성 오차가 **소수점 아래까지 0.0%의 완벽한 일치(Exact Match)**를 완수하였습니다!
