# Walkthrough - Real-Time Monitor Layout Fix (2026-05-26)

실시간 시뮬레이션 모니터(`WHTS Real-Time Monitor`) 창 우측 범례(Legend) 영역 바깥쪽의 불필요한 빈 공간(마진)을 제거하고, 범례와 플롯 사이의 간격을 가독성 있게 최적화하며, 여러 개의 중복 범례를 하나의 깔끔한 Figure 레벨 범례로 통합 및 토글 제어가 가능하도록 변경하는 작업을 진행했습니다.

## 변경 사항

### [run_drop_simulator/whts_monitor.py](file:///c:/Users/GOODMAN/WHToolsBox/TVPackageMotionSim/run_drop_simulator/whts_monitor.py)

- **Matplotlib Subplots Layout 및 범례 앵커 조정**
  - 기존 코드에서는 범례(Legend) 영역 공간 확보를 위해 `fig.subplots_adjust(right=0.78)`로 우측에 **22%**의 고정 여백을 남기도록 설정되어 있었습니다.
  - 범례 텍스트("C1"~"C8")의 너비가 좁아 실제 필요한 폭보다 너무 과도한 검은색 빈 공간이 생겼던 부분을 개선하기 위해 여백 비율을 **12%** (`right=0.88`)로 조정하여 플롯 가로폭을 시원하게 늘렸습니다.
  - 동시에 범례 박스가 플롯의 우측 선에 너무 바짝 달라붙지 않도록, `bbox_to_anchor`의 X축 시작 위치를 기존 `1.01`에서 **`1.05`**로 늘려 약 5%만큼의 띄움 간격을 추가로 확보했습니다.

- **단일 통합 범례 적용 및 View 풀다운 메뉴 제어 기능 탑재**
  - **통합 범례 구성:** 창 내의 모든 subplot마다 동일하게 표기되던 중복 범례들을 모두 삭제하고, 첫 번째 subplot에서 얻은 단일 legend 정보로 Figure 레벨에서 하나만 생성하여 창 전체의 우측 상하 중앙(`loc='center left'`, `bbox_to_anchor=(0.89, 0.5)`)에 통합 안착시켰습니다.
  - **View 메뉴 범례 토글:** `🔍 View` 메뉴에 `📋 Show Legend` 라는 체크 방식의 액션을 추가했습니다.
  - **여백 자동 스위칭:** 범례가 켜져 있을 때는 플롯의 우측 마진을 `right=0.88`로 설정하고, 사용자가 범례를 끄면(`Show Legend` 체크 해제) 플롯을 화면에 꽉 차게 표시하도록 `right=0.96`으로 여백을 자동 조절하는 레이아웃 스마트 대응 로직을 추가했습니다.

- **Model 풀다운 메뉴의 "최근 파일" 텍스트 영어화**
  - **다국어 가독성 통일:** 메인 컨트롤 패널 UI의 상단 `Model` 풀다운 메뉴 중에서 한글로 남아있던 `"최근 파일"` 항목의 텍스트를 글로벌 가독성을 위해 **`"Recent Files"`**로 영어화하였습니다.
  - **아이콘 유지:** 기존의 🕘(시계) 이모지 아이콘은 그대로 유지하여 시인성을 확보하였습니다.
